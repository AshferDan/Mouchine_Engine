Moustach've Been The Wind is a single-player 2D speedrunning platformer where you play as Mr. Mouch, a grumpy barber on a 
frantic race to fix haircut disasters using chained powerful movement abilities while navigating fast-paced challenging
levels with precision.

===========================================================================================================

Player Controls

- Movement
  A                    	Walk Left
  D                   	Walk Right
  Spacebar             	Jump

System

- Mouse
  Left click          	Control IMGUI Windows

- Debug
  F1                    Toggle debug mode

- Batch Rendering
  1                  	Spawn 2500 entities on screen
  2                   	Destroy all entities

- Audio
  M			Pause the BGM sound

- Game State
  ESC			Quit the game

===========================================================================================================

Required folders and files :

Folders : Build, Assets, Engine, Extern, Game, Logs, Shaders, cmake, CMakeFiles
Files 	: config

Once you verified you possess all the required folders and files, run the "script_build_and_run" batch file.

Open the GAM_200_AME solution in the Build folder and set up Game project as your Startup Project
